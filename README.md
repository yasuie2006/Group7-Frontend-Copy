# Group 7 - E-Commerce Frontend

## Project Description

The Group 7 E-Commerce Frontend is a web application developed using ReactJS and Vite. It connects to a Laravel REST API backend to provide product management, user authentication, and role-based access control.

## Technologies Used

- ReactJS
- Vite
- Material UI (MUI)
- Axios
- React Router
- Laravel REST API
- MySQL

## Features

- User Registration and Login
- User Authentication using Laravel Sanctum
- Persistent Login Session
- User Logout
- Protected Routes
- Admin-
